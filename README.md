# Goal   
Maybe you think Linux is cool , a computer science major that want to learn about the low level , sysadmin want Linux utilitys or any one how want to use Linux system .   

In this repository you will learn the basis of GNU/Linux systems in general to use it as your main operating system and how it's works in high level overview and some more benefits .   

It suppose to be very beginner friendly, and in all languages by the help form contributors form over the world .    

The docs will focus on Debian system , however many topics will work on others distros as well .   
   
# Philosophy
This project isn't about perfection ,it's about collaboration, with help from the GNU/Linux community.

I'am not a Linux expert that worked on Linux kernel ,or a sysadmin with a many deaced experience ,am just a computer guy Linux enthusiasm who want to learn GNU\Linux and use it as my (for life) main operating system .
