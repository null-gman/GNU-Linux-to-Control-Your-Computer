# Goal
Maybe you think Linux is cool ,a computer science major that want to level up his/her skills ,a sysadmin want to use Linux utilities ,or any one how want to use Linux system in general.

In this repository i will try(and the Contributors) to write down the basis of GNU/Linux systems in general to use it as your main operating system and how it's works in high level overview and some more information .

It suppose to be very beginner friendly . The docs will focus on Debian system , however many topics will work on others GNU/Linux Distributions as well .

# Philosophy
This project isn't about perfection ,it's about collaboration, with help from the GNU/Linux community. I'am not a Linux expert that worked on the Linux kernel ,or a sysadmin with a decades of experience ,am just a computer guy Linux enthusiasm who want to learn GNU\Linux and use it as my (for life) main operating system .

Maybe i will make a typo or even input a false information in this document , so i counting on you (GNU/Linux community) to correct me by collaboration and report issues .

I know there are many Linux resources out there , however why not increasing the recourse by 1 . And when i started GNU/Linux journey i learned form many different places and there are core consents that are rarely talking about , so that i want this GNU/Linux guide to be very comprehensive for beginners , you will not be a sysadmin ,however you will learn how to use your GNU/Linux systems .
